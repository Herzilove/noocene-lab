# Three-minute prototype demonstration

1. Open the landing page on a narrow/mobile viewport and start Mind Quest without registration.
2. Leave optional research/AI consent off. Give an initial answer and confidence, read the reflection, and revise the answer. Show the objective explanation and before/after confidence. Condition is randomized; repeat if the independent condition was assigned.
3. Open INNERSPACE with a clearly fictional meeting example. Move through noticing a reaction, a possible different perspective and a chosen future action. Show that reset removes the current narrative.
4. Run `pnpm research:reproduce`. Open its report and SVG. Show the hypothesis, synthetic label, validation, hashes and next-proposal approval boundary.
5. State the limits: one reasoning item, scripted default, no human efficacy study, no durable study storage. Live Claude integration exists but still needs credentialed verification.

Research question: Does Socratic AI-guided reflection improve reasoning or confidence calibration compared with independent reflection?

The demonstrated result is an executable prototype and validated synthetic analysis pipeline. It is not evidence that the intervention improves metacognition.
